# ☕ 온기 커피 (ONGI COFFEE) 랜딩 페이지

가상의 스페셜티 카페 **"온기 커피"**를 소개하는 한 페이지짜리 웹사이트입니다.
AI 에이전트 수업에서 Claude Code로 웹 페이지를 만들고 GitHub에 올리는 과정을 연습하려고 만든 예제 프로젝트입니다.

## 📁 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지의 내용과 구조 |
| `style.css` | 색상, 글꼴, 레이아웃 등 디자인 |
| `README.md` | 이 폴더를 설명하는 문서 (지금 보고 있는 파일) |

## 🧩 페이지 구성

1. **상단 메뉴**: 로고와 소개 · 메뉴 · 오시는 길 바로가기
2. **대표 이미지 영역**: 커피 사진 배경 위의 소개 문구와 "메뉴 보기" 버튼
3. **우리의 이야기**: 직접 로스팅, 공정 무역 원두, 매일 굽는 디저트
4. **대표 메뉴**: 커피와 디저트 6가지와 가격
5. **오시는 길**: 주소, 영업시간, 문의처
6. **푸터**: 저작권 표시

## 🛠 사용 기술

- HTML5, CSS3 (프레임워크 없이 직접 작성)
- Google Fonts: Noto Serif KR, Noto Sans KR
- 반응형 디자인: PC와 모바일 화면 모두 지원

## 🚀 실행 방법

따로 설치할 것 없이 `index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다.
배경 사진과 글꼴은 인터넷에서 불러오므로 인터넷이 연결되어 있어야 제대로 보입니다.

## ⚠️ 참고

카페 이름, 주소, 전화번호, 메뉴와 가격은 모두 연습용으로 지어낸 정보입니다.
